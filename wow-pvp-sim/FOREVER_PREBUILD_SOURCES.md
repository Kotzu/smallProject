## Validation rule
- Preset rank maps are decoded from the current public calculator links.
- The allocator maps every selected talent by **name** onto the live Forever dataset.
- Candidate must contain exactly 51 points and pass max-rank, tier and prerequisite checks.
- Invalid/outdated presets fail atomically: the player's existing build is preserved.
- Manual editing after applying a preset marks it `CUSTOMIZED`.
- Popularity determines only the default convenience preset for a matching class/spec; it is not an evaluation of strength.
